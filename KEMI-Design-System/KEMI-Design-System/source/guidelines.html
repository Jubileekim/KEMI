아래의 수정 규칙 → 타이포그래피 → 기존 브랜드 보드와 컴포넌트 순서로 확인하세요. 이전 예시와 충돌하면 이 수정 규칙을 우선합니다. 로고·팔레트 10색·기존 라운드는 유지합니다.

Primary Color · 색의 역할

대표색은 브랜드를 기억하게 하고, 행동색은 무엇을 누를지 알려줍니다. text-primary는 기본 본문색이라는 뜻입니다.

버튼 · 입력 · 선택 상태

일반 작업 화면에는 단색 주요 버튼을 사용합니다. 같은 행동 묶음의 Primary는 1개를 기본으로 하고, 나머지는 Secondary·Ghost로 구분합니다.

Hover 예시 Pressed 예시 Focus 예시

버튼은 문서 시연용입니다. 문의 전송·삭제는 실행되지 않습니다. Hover·Pressed·Focus 표본은 비교용입니다.

요소상태표현·동작
버튼기본 / hover / pressed / focus / disabled / loading동작을 설명하는 라벨. 처리 중 중복 조작 방지·폭 유지·상태 안내. 비활성 이유는 주변 설명으로 제공.
입력기본 / focus / error / disabled / readonly항상 라벨 제공. placeholder로 대체하지 않음. 오류 문구를 입력과 연결하고 작성값 유지.
체크·라디오·칩미선택 / 선택 / focus / disabled체크 마크·문구·테두리로 선택 표시. 단일 선택과 복수 선택을 구분.
아이콘 버튼기본 / 선택 / focus / disabled접근 가능한 이름 제공. 눌러서 바뀌는 상태는 aria-pressed. 이동은 링크, 동작은 버튼.

문서 시연용입니다. 실제 문의 양식과 입력 제한은 제품 명세에서 정합니다.

사용 목적을 입력해 주세요.

오류는 해당 필드 아래에 구체적으로 표시하고 첫 오류로 이동합니다. 서버 오류가 나도 입력·선택을 지우지 않습니다. 긴 입력창과 textarea는 가독성을 위해 캡슐형 대신 16px 라운드를 적용합니다. 버튼·카드·모달의 기존 라운드는 유지합니다.

데스크톱 · 1024px 이상좌우 32px, 콘텐츠 최대 1280px, 카드 3–4열. 문의 본문은 최대 70ch.필터는 좌측 240px, 모달 기본 최대 560px. 내용이 길면 내부 스크롤.

이 수치는 제품 화면의 시작 기준입니다. 문서 탐색 메뉴는 콘텐츠 확보를 위해 1024px 미만에서 상단으로 이동합니다. 표는 지역 스크롤을 허용하되 페이지 전체 가로 스크롤은 피합니다. 200% 확대 시에도 내용·주요 행동에 접근할 수 있어야 합니다.

현재 서비스 패턴 · 탐색부터 상담까지

1. 작품 탐색

검색·목적·비율 필터, 작품 상세, 이런 느낌 더 보기.

유사 탐색에서는 기준 작품과 이전 탐색 복귀를 표시합니다.

2. 저장과 문의 선택

북마크 저장과 문의용 체크는 별도 행동입니다.

제작자별 묶음·작품 개수·선택 한도를 함께 보여줍니다.

3. 문의 검토·전송

공통 요청과 제작자별 참고 작품을 확인합니다.

일부 실패하면 성공은 유지하고 실패한 대상만 재시도합니다.

4. 답변·상담·종료

답변 전에는 고객 파일 첨부 잠금 이유를, 답변 후에는 자료 공유를 표시합니다.

종료·차단·공유 해제 상태와 가능한 다음 행동을 안내합니다.

목록과 전송의 상태 예시

문서 시연이며 실제 검색·전송·재시도가 아닙니다. 성공은 실제 서버 응답 이후에 표시합니다. 결과 확인이 필요한 전송 오류는 무조건 재전송시키지 않고 먼저 상태를 확인합니다.

영역규칙예시·확인
아이콘16 / 20 / 24px, 선형 1.75–2px 중 한 계열로 통일. 글자와 8px 간격. 단독 버튼 터치 영역 44×44px 권장.저장 전·후는 윤곽/채움 + 접근 가능한 이름·선택 상태. 작은 아이콘 자체와 터치 영역을 구분.

영상재생·시간·음소거 컨트롤 위치 고정. 저장은 우상단, 시간은 하단. 조작 영역 겹침 방지.자동 소리 재생 금지. reduced-motion에서 자동 미리보기 제한. 영상 위 글자는 대비 표면 제공.
키보드·모달Tab 순서와 포커스 표시. 모달은 이름·설명 제공, 내부 포커스 유지, 닫힌 후 원래 조작으로 복귀.Escape 닫기 지원. 중요 삭제·전송은 행동의 결과를 설명하고 확인 기회 제공.
알림·오류색·아이콘·문구를 함께 사용. 처리 상태는 보조 기술에도 전달. hover에만 필수 정보 배치 금지.‘실패’ 대신 ‘문의가 전송되지 않았어요. 작성 내용은 유지했어요.’
문구행동과 대상을 명확히 표시. 완료·가능·확정은 실제 상태와 일치.‘확인’보다 ‘문의 보내기’, ‘저장 삭제’보다 ‘저장함에서 제거’. 상담은 계약·최종 선정이 아님.

본문·입력·필터·문의·상담은 읽기 쉬운 불투명 표면을 사용합니다. Liquid Glass는 재생·저장 등 작은 포인트에 제한하고 장식으로 이해를 방해하지 않게 합니다.
