# PDF 기준 프론트엔드 실행과 시연

기능 요구사항은 사용자가 제공한 `단계별_개발_계획.pdf` 5쪽만 사용했다. 이 폴더는 독립 실행 예제이며 기존 저장소의 `apps/web`, API, shared 패키지를 변경하지 않는다. 요구사항 원본 PDF는 소스코드 패키지에 포함하지 않았다.

## 실행

Node 24, npm 11에서 루트 폴더를 열고 실행한다.

```powershell
npm ci
npm run dev
```

접속: http://127.0.0.1:5173

```powershell
npm run test:pdf
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run preview
```

추가 환경변수나 비밀키 없이 실행한다. 기존 `VITE_ENABLE_MOCKS` 개발 프로브와 별개로, 이번 화면은 브라우저 내 시연 상태를 사용한다. 내장 영상은 이 작업에서 생성한 3초 추상 애니메이션이며 고객 콘텐츠가 아니다.

## 시연 방법

상단의 **시연 역할**에서 의뢰인·제작자를 바꾼다. 두 역할의 행동을 한 브라우저에서 번갈아 실행하는 방식이며 실제 두 계정 인증이나 서버 권한 검증은 아니다. 운영 역할도 로컬 시연 도구다.

1. 공개 모집: 제작자로 `/campaigns`에서 제안 → 의뢰인으로 제안 수락 → 대화·작업 공간 열기.
2. 직접 의뢰: 의뢰인으로 작품 → 제작자 프로필 → 직접 의뢰 발송 → 제작자로 수락 → 같은 대화·작업 공간 열기.
3. 조건 합의: 범위·금액·제작일·수정 횟수를 작성 → 48시간 확인 요청 → 양 역할에서 같은 버전에 서명. 첫 서명으로는 계약이 확정되지 않는다. 변경은 새 버전으로 작성한다.
4. 결제·제작 준비: 의뢰인이 로컬 결제 확인 중/실패/성공을 조작 → 의뢰인이 자료 제공·발송 기록 → 제작자가 정상 수령 확인 → 시연 납기를 지정하고 제작 시작. D09가 미결정이므로 기산일을 자동으로 추정하지 않는다.
5. 납품·검토: 제작자가 초안·검토본 제출 → 의뢰인 수정 체크리스트 → 제작자 수정본 제출 → 의뢰인 최신 검토본 승인 → 제작자 최종 파일 제출 → 의뢰인 시연 파일 다운로드 및 별도 최종 수령 확인.
6. 완료·리뷰: 200,000원 계약은 수수료 20,000원, 모의 지급 180,000원. 의뢰인·제작자가 정상 완료 거래에 한 번씩 리뷰한다.
7. 취소·부분 환불: 별도 유료 거래에서 대가 80,000원과 파일·미완성 상태·사용권을 합의 → 양측 승인 → 로컬 환불 성공 반영 → 인도 파일 확인. 환불 120,000원, 수수료 8,000원, 모의 지급 72,000원.
8. 분쟁: 증빙 기록 → 거래 진행과 정산 보류 → 대화·증빙은 유지 → 운영 시연 역할에서 처리 근거를 남기고 보류 해제.

브라우저 `localStorage`에는 시연 거래·메타데이터만 저장한다. 역할은 탭의 `sessionStorage`에 저장된다. 비밀번호·이메일·토큰·선택한 파일 본문은 저장하거나 전송하지 않는다. 브라우저 저장 제한 시 메모리에서만 동작한다. 푸터 **시연 도구**에서 로딩·빈 결과·오류 상태와 데이터 초기화를 사용할 수 있다.

## 검증 자료

- 최종 로컬 결과: 상태 전이 테스트 **20/20**, Edge 브라우저 시나리오 **16/16**. 타입 검사·ESLint·포맷 검사·프로덕션 빌드 통과. 브라우저 시나리오에서 페이지 JavaScript 오류 없음, 390px 홈/모집/작업 공간 가로 넘침 없음.
- 상태 전이 회귀 테스트: `apps/web/tests/pdf-flow.test.mjs` (`npm run test:pdf`).
- 브라우저 시나리오: `qa/pdf-frontend/browser.mjs`. Microsoft Edge와 Playwright가 필요하다. 기본값은 설치된 `playwright` 패키지다. 별도 도구 경로를 사용하는 경우 `KEMI_PLAYWRIGHT`를 설치된 Playwright의 `index.mjs` 절대 경로로 지정한다. `KEMI_URL`로 실행 중인 테스트 서버 주소를 바꿀 수 있다.
- 화면 캡처와 실행 결과: `qa/pdf-frontend/`.
- 영상 재생 샘플 생성: `qa/pdf-frontend/media.mjs`. 같은 Playwright 경로 설정을 사용한다.

이 검증은 프론트엔드 시연의 검증이다. PDF에 적힌 실제 API·DB·외부 서비스·배포 완료 기준을 충족했다는 의미는 아니다. D01–D22의 미결정 세부 정책은 다른 문서에서 가져와 채우지 않았다.
