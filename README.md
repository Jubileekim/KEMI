# 2팀 프로젝트

소상공인과 크리에이터를 연결하는 UGC 영상 제작·납품 플랫폼의 팀 개발 저장소입니다.

## 주요 흐름

- 공개 모집: 캠페인 등록 → 제안서 제출 → 선정 → 계약
- 직접 의뢰: 프로필·포트폴리오 탐색 → 개별 의뢰서 → 수락·조건 확정 → 계약
- 계약 이후: 제작·납품 → 검토·승인 → 정산·리뷰
- 결제 방식과 세부 정책은 팀 논의 후 확정합니다.

## 협업 규칙

1. 각자 본인의 GitHub 계정으로 참여합니다.
2. 최신 main에서 작업별 브랜치를 만듭니다. 예: feat/creator-profile, feat/campaign
3. 개발 작업은 main에 직접 올리지 않고 PR로 요청합니다.
4. PR에 변경 내용과 확인 방법을 적고, 팀원 검토 후 합칩니다.
5. DB 스키마와 공통 API 변경은 팀원과 먼저 공유합니다.
6. 실제 .env, API 키, 비밀번호, node_modules는 저장소에 올리지 않습니다.
7. 포트폴리오·납품 영상은 별도 파일 저장소에 저장하고 링크로 연결합니다.

## 개발 준비

기술 스택, 실행 방법, 폴더 구조, 환경변수 예시는 팀 합의 후 추가합니다.
