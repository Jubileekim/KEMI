## 패키지·대표·공개

- `/studio/packages`에서 여러 독립 상품을 초안·공개로 저장하고 수정·비공개 처리한다. 제목·설명·가격·규격·수량·포함/제외 범위·자료·기간·수정·원본·사용권을 한 화면에서 확인한다.
- 패키지는 P05의 협의 출발점이며 옵션 구매를 추가하지 않는다. 미완성 초안은 허용한다. 공개 후보는 누락 조건·가격 형식·상업 광고 활용 가능 여부를 검사한다.
- P04의 공개 대표 1개를 명시적으로 선택한다. 자동 지정하지 않는다. 대표 ID 하나를 변경하는 모의 원자적 명령으로 동시에 대표 둘이 되는 상태를 방지한다.
- 프로필·상품 저장으로 서비스가 공개되지 않는다. D01 UNKNOWN/MISSING은 공개를 막고, 개발 전용 READY와 공개 대표가 있을 때만 모의 공개한다. 작업물은 공개 필수 조건이 아니다.
- 서비스 비공개는 모의 노출/신규 활동을 차단하고 별도 보관된 모의 계약 참조를 유지한다. 실제 탐색·직접 의뢰·제안·협의·계약·납품 기능은 연결하지 않았으므로 해당 서버 권한을 검증한 것은 아니다.
- 공개 서비스의 대표를 비공개로 바꾸는 동작은 선행 조치를 안내한다. 다른 공개 대표를 먼저 지정하거나 서비스를 명시적으로 비공개로 바꾸면 진행할 수 있다. 비공개 서비스에서 상품을 숨기면 대표를 해제한다. 서비스 자동 전환은 구현하지 않는다.

## 실제 API와 Mock

`docs/api문서.txt`·기능표의 7개 기능은 API 미정의다. 현재 shared의 서비스 상태 enum은 존재하지만, 프로필 PATCH에서 `serviceStatus`는 금지된다. API/shared·Prisma·DB 계약을 추가하거나 PATCH를 우회하지 않았다.

운영 화면은 계약 준비 안내만 보여 준다. 개발 모드와 `VITE_ENABLE_MOCKS=true`가 모두 충족돼야 lazy import된 Mock 화면/어댑터가 열린다. `/__mock__/studio`는 가상 모의 명령 전용이며 제품 API 제안으로 간주하지 않는다. 인증은 기존 메모리 세션을 사용하고 Mock 요청에만 fixture 토큰을 붙인다. 세션 epoch와 조회 취소·개인 Query 캐시 초기화·쓰기 재시도 금지를 유지한다.

Mock은 계정별 모듈 메모리와 revision으로 저장·충돌을 검사한다. 지연 중 계정이 바뀌면 쓰기를 거절하고 늦은 응답을 표시하지 않는다. 전체 새로고침하면 모의 데이터가 초기화된다. Query 최신 값 조회 실패 시 기존 편집 폼을 유지한다. 오류·성공·로딩·빈 상태를 구분한다.

`모의 계약 참조 보관`은 별도 복사한 테스트 참조다. 이후 상품 가격·범위 변경과 서비스 비공개로 바뀌지 않음을 검사한다. 실제 계약/제안 snapshot 저장 API·DB 보존을 구현하거나 입증한 것이 아니다.

## 작업물 등록·수정·비공개·삭제

- `/studio/portfolio`에서 PORT-01·02를 개발 전용 Mock으로 제공한다. 제목·설명·본인 역할·스타일/작업유형·자작 샘플/외부 고객/플랫폼 작업·출처·공개 권한·고객 동의를 편집한다. 미완성은 초안으로 저장한다.
- 자작 샘플은 거래 이력·후기 없이 등록할 수 있다. 고객/플랫폼 작업의 공개 후보 저장에는 동의가 필요하며 거래물을 자동 가져오거나 공개하지 않는다. 공개 후보라도 서비스 비공개 상태에서는 모의 노출 목록에서 즉시 제외한다.
- 파일 선택·로컬 미리보기·명시적 Mock 업로드 완료·작업물 저장을 분리한다. 파일 bytes는 서버로 전송하지 않고 이름/MIME/크기/모의 준비 상태만 모듈 메모리에 보관한다. 실제 업로드 성공 표시가 아니다. 미리보기 재생 준비 실패는 완료 처리/공개를 차단한다. 파일 변경·취소·화면 이동/로그아웃 때 blob URL을 해제한다.
- MP4/WebM·0초과 50MiB 이하의 후보 보호 한도는 **로컬 시연 한도**다. 실제 저장소의 파일 크기/형식/검증 정책으로 확정하지 않는다. 편집 재진입에는 이전 메타데이터만 있으므로 재생하려면 파일을 다시 선택한다.
- D02 미결정 때문에 외부 URL은 자격 정보 없는 https 형식의 초안으로만 보관한다. 허용 제공자 목록을 임의로 만들거나 외부 링크를 열고 임베드/요청하지 않는다. URL 공개·외부 제공자 재생 검증은 미완료다.
- D21 스타일/작업유형을 임시 자유 입력으로 표시한다. 기존 shared 본인 역할 선택지만 사용한다. 추천·공개 피드/정렬/필터·직접 의뢰 연결은 6단계 범위이므로 추가하지 않는다.
- 삭제 모달에서 대상과 영향을 안내한다. 취소·처리 중·실패/명시적 재시도를 구분하고 성공 후 내 목록과 공개 후보에서 제외한다. `모의 제출 참조 보관`은 별도 복사한 **메타데이터**를 수정·비공개·삭제 뒤에도 유지하는 예시다. 실제 제안/계약·파일 bytes의 보존 방식은 D02로 남는다.

## 미결정과 필요한 계약

| 항목           | 유지한 경계                                                                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D01            | 크리에이터 공개 필수 프로필 항목 미확정. 실데이터로 완료 판정하지 않고 UNKNOWN/READY/MISSING fixture로만 검증한다.                                                                                            |
| D03            | 첫 대표 자동 지정·마지막 공개 상품 비공개 연동·추가 개수·삭제·정렬 미확정. 자동화·개수 제한·상품 삭제/정렬을 추가하지 않는다. 대표 유지가 불가능한 전이는 명시적 선행 조치로 안내한다.                        |
| D02/D21        | 파일·외부 URL 허용/검증·실제 업로드/재생·제출 당시 bytes 보존·분류 선택값/노출 정책은 미결정이다. URL은 초안만, 파일은 로컬 Mock, 분류는 임시 자유 입력이다.                                                  |
| Mock 입력 한도 | 문자열 4,000자, 가격·수량·기간은 양의 안전한 정수, 수정은 0 이상 정수로 임시 검사한다. 안전한 시연을 위한 후보 기준이며 팀 확정 상한·가격 정책이 아니다. 공개 시 각 조건은 `없음` 등으로 직접 설명할 수 있다. |
| 실제 API       | 본인 상품 CRUD/버전·대표 단일성·서비스 공개 원자성·D01 검사·신규 활동 권한·기존 거래 보존·파일/권한 계약이 필요하다.                                                                                          |
