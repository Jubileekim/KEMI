참고 자료: `api문서.txt` (OpenAPI 3.1 문서를 만드는 TypeScript 소스, 26개 경로·33개 동작). **명세 일치**는 문서에 드러난 동작 수준에서 주요 의미가 맞는다는 뜻이며, 구현·실서버·전체 입력 스키마 검증 완료를 뜻하지 않는다. `@kemi/shared`의 enum과 요청 스키마 원본이 없어 정확한 필드·선택값은 추가 확인해야 한다.

- **수정 필요:** 일부 API만 있거나, 명세와 충돌하거나, 필수 동작의 문서화/정의 보완이 필요하다. 서버 구현 자체의 오류로 단정하지 않는다.
- **API 정의 없음:** 이 파일에서 해당 기능을 수행하는 경로/동작을 찾지 못했다. 다른 서버 코드에도 없다는 뜻은 아니다.
