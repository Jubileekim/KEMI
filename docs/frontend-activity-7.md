# 7단계 활동·알림·운영·분석

기준: 기능명세서 REVIEW-01/NOTI-01/02/BOOK-01/REC-01/OPS-01/METRIC-01,
P18/P19/P25, 계획 §7, 기능별 API 대조. 원본 KEMI의 6-C 미커밋 변경은
보존하고 확인된 6-B `8fecb83`에서 별도 worktree로 작업한다.

## 작업 순서와 완료 조건

1. 7-A: `features/activity/ActivityPage.tsx`, `mocks/activity-{model,api,handlers}.ts`,
   `ActivityMock.tsx`에 본인 모집·의뢰·계약 목록, 크리에이터 저장·해제와 추천 이유를 연결한다.
   기존 모집 상세에서 저장하고 메뉴에서 본인 목록에 진입한다. 모델 단위, 양 역할/타인·중복·오류
   E2E, build:web 후 검토·커밋·푸시·Draft PR.
2. 7-B: `mocks/engagement-*`, `EngagementMock.tsx`, 활동 경로에 본인 알림/읽음,
   정상 수령 완료 거래의 양측 각1회 리뷰 연결. 성공한 기존 거래 기록에서 알림을 유도한다.
   실패 사건은 성공 알림을 만들지 않고 알림 실패가 거래를 변경하지 않는다. 역할/중복/미완료
   검사 후 별도 PR. 상단 알림 수와 채팅 미확인 수는 분리한다.
3. 7-C: `mocks/safety-*`, `SafetyMock.tsx`, `shared/analytics/events.ts`에 신고·검토·
   이용 제한 안내·이의와 개인정보 없는 테스트 이벤트를 연결한다. 기존 거래/납품 접근 유지,
   수동 운영 조치/자동 제재 없음, 분석 실패 격리·거래 이벤트 중복 방지 검사 후 PR.
4. 각 기능 종료 후 7단계 메뉴→저장/추천→활동→완료 거래 리뷰·알림→신고/이의의 통합을
   데스크톱/모바일에서 확인한다. 운영 빌드의 Mock 제외와 기존 인증 제한도 확인한다.

## API 및 미결정 경계

- 서버/shared에 `/api/bookmarks/projects`·추천·알림 조회/읽음이 존재한다.
  기존 프론트 모집은 `__mock__/discovery`의 별도 Campaign DTO/메모리이며 실제 Project와
  계약·ID·수명주기가 다르다. 둘을 섞어 실서버 북마크로 보내지 않는다.
- 추천 API는 이유/정보 부족 구분을 제공하지 않고 최신 목록 fallback을 사용한다.
  활동 집계·리뷰·신고·제재·분석 API도 없다. 7단계의 누락된 계약은 `__mock__`로 명시한다.
- D14 리뷰 공개 시점/수정·삭제·태그 제한/취소 리뷰를 확정하지 않는다. 정상 수령 완료만 허용하고
  작성자 본인 기록만 보여주며 공개/상대 알림은 보류한다. 입력 길이는 개발용 보호값이다.
- D15 최종 추천 규칙/일정 데이터·비공개/삭제 저장 목록 처리 미결정. 추천은 현재 프로필
  분야와 일치하는 공개 모집의 개발 예시이며 스타일/일정 적합을 주장하지 않는다.
- D18 운영 권한/조치·이의 범위 미결정. DEV fixture의 운영자만 테스트 안내 상태를 변경한다.
  실제 SUSPENDED/RESTRICTED 계정은 기존 인증 컨트롤러가 거부하므로 운영 인증 정책을
  바꾸지 않고 원인을 기록한다. DEV 제한 안내와 실제 인증 제한을 구분한다.
- D22 도구/동의/저장/보존 미결정. 운영 수집은 연결하지 않는다. 테스트 기록은 메모리만 사용한다.
- 새로고침/사이트 종료·다중 기기/영구 복원은 Mock으로 보장하지 않는다. 인앱 부재 중 보관은
  같은 SPA 탭에서 화면을 떠난 동안만 검증 가능하다. 실제 NOTI-01 전체 완료는 아니다.

## 실패 시나리오와 방어

지연 중 계정 변경은 Bearer/epoch 재검사, 입력은 strict Zod, 중복 저장/읽음/리뷰는
서버 역할의 Mock 처리기에서 멱등·유일성 검사. 조회 오류는 이전 데이터를 성공 화면으로
표시하지 않고 수동 재조회한다. 응답 유실 뒤 목록 재조회로 확인하며 자동 재시도하지 않는다.
데이터/권한 검증은 실제 서버 보안 증거가 아니다. 페이지/대량 처리와 영구 저장은 후속 API 경계다.
