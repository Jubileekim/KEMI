## 실험 목적

- **작품 탐색:** 제작자 프로필을 일일이 열지 않고 완성 영상의 스타일을 먼저 보고 탐색하는 경험을 시험한다.
- **영상 단위 북마크:** 같은 제작자의 다른 작품도 각각 선택할 수 있고, 선택한 영상은 문의 참고자료가 된다.
- **문의 단순화:** 예를 들어 영상 4개를 고르되 제작자가 3명이면 제작자별 문의 대상 3명으로 묶는다.
- **명확한 경계:** 북마크만으로 문의하지 않는다. 데모 내 발송도 실제 메시지 전송이 아니다.

## 실행 방법

1. [HTML 원본](prototypes/wedding-video-request.html)을 GitHub에서 내려받아 Chrome/Safari 등 브라우저로 연다.
2. 화면 버튼을 클릭하며 6단계 사용자 여정을 확인한다. 상단 회의 포인트에서 미결정 사항을 검토할 수 있다.
3. 필요하면 초기화 후 다시 시작한다.

원본 HTML 안에 디자인, 스크립트, 시연용 이미지가 포함되어 있으므로 별도 빌드나 서버가 필요 없다. **실제 회원가입·DM·계약·결제·납품·정산·리뷰를 수행하지 않는다.** 표시되는 이름, 샘플 작업과 입력 정보는 예시이다.
